# Системи глибинного навчання

Лабораторні роботи студентки групи КМ-31 Семеряги Софії.

| Тека | Робота |
|---|---|
| `lab1/` | ЛР1. Реалізація та перевірка зворотного поширення похибки |
| `lab2/` | ЛР2. Поріг рішення під асиметричну ціну помилок |

Кожна робота є окремим uv-проєктом, тому команди запуску з її README
виконуються з теки цієї роботи, наприклад:

```bash
cd lab2
uv run python main.py
```
